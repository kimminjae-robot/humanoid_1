# 키모도 프로젝트 정리

기준일: 2026-10-22. 목표는 텍스트에서 생성한 사람형 모션을 로봇에 옮기고, 중력·접촉·모터 제한이 있는 시뮬레이션에서 실제로 추종하는 것입니다. 화면에서 자세가 재생되는 것과 물리 추종 성공을 구분했습니다.

## 1. G1: 생성에서 동일 정책 sim-to-sim까지

공식 Kimodo-G1-RP-v1과 CPU의 공식 Llama/LLM2Vec 인코더로 모션을 생성했습니다. 원본 15개를 보존하고, 관절 순서·좌표·속도·발 접촉 등을 검사해 50Hz reference 14개를 채택했습니다. 걷기 train33은 거부 이력에 남겼습니다. Qwen 대안은 실험 경로였고 기준 결과는 공식 인코더입니다.

Isaac Lab 2.3.2 / RSL-RL PPO 추종기를 구현하고, 검증된 balance MLP를 고정한 상태에서 residual MLP를 학습했습니다. 관측 194차원·행동 29차원, 정책 50Hz·명시적 PD 500Hz입니다. 학습 정책을 TorchScript로 export해 MuJoCo에서 같은 정책과 저장된 동일 초기 상태로 60개 episode를 평가했습니다.

| 동작 | Isaac | MuJoCo 2ms | MuJoCo 1ms |
|---|---:|---:|---:|
| 서기 | 20/20 | 20/20 | 20/20 |
| 손 흔들기 | 20/20 | 20/20 | 20/20 |
| 느린 걷기 | 0/20 | 0/20 | 0/20 |

프레임워크 연결은 완료했습니다. 걷기 성능 때문에 전체 성능·배포 gate는 미통과입니다. MuJoCo 걷기는 약 2.00~2.42초에 넘어졌습니다. 다음 개선은 지지발 전환·COM/ZMP·시간 연속성을 고려한 reference 개선이며, 같은 실패 PPO 실험을 단순히 연장하는 것은 채택하지 않았습니다. final 생성 seed는 튜닝에 사용하지 않았습니다.

근거: [stage 4](../workspaces/g1_kimodo/reports/stage_04.md), [stage 5](../workspaces/g1_kimodo/reports/stage_05.md).

## 2. K1 + HX5: 로봇 결합과 제한된 동작 물리 성공

공식 AI Sapiens K1 몸체 23관절에 ROBOTIS HX5-D20 양손 각 20관절을 결합했습니다. 총 63관절, 자유 베이스 포함 nq=70/nv=69, 질량 약 36.80861kg입니다. 기존 고무 손 질량을 제거하고 공식 손의 질량·관성·충돌을 반영했습니다. 손가락 목표는 일정하며 손 조작은 구현 범위에 포함하지 않았습니다. 장착 좌표는 시뮬레이션 가정입니다.

Kimodo의 G1 모션을 K1에 IK로 옮겼습니다. 서기·wave는 기존 balance 제어로 각각 3/3 성공했습니다. 걷기는 처음 실패했으나 원본의 발 이동을 30%로 줄이고 체중 이동·swing을 각각 3초로 느리게 조건화한 뒤 centroidal 지면반력 QP와 torque PD로 2개 clip × 3 reset = 6/6 통과했습니다. 약 0.302/0.368m 전진했습니다. 원래 보폭·속도와 상체 스타일의 전체 재현은 아닙니다.

근거: [걷기 개선](../workspaces/k1_kimodo_hx5/reports/walking_improvement.md).

## 3. 경례 개선과 새 모션 실패

새 경례는 생성과 참조 재생에는 성공했지만 자기 충돌 44.24mm와 부적절한 발·root 이동으로 QA 실패, 물리 0/3이었습니다. 양발 고정·COM 정렬·팔 충돌 회피 IK·복귀 경로 수정 후 `--controller centroidal`로 QA와 물리 3/3을 통과했고 각 6.96초를 완료했습니다. 1ms timestep에서도 같은 초기 상태로 3/3을 유지했습니다. nominal 최대 실제 자기 침투는 약 0.76mm였습니다.

보정은 모션을 바꿉니다. root 이동 수정은 최대 15.67cm, 팔을 내리는 오른손 경로 수정은 최대 15.97cm, 팔 관절 수정은 최대 0.55rad입니다. 경례 유지 구간의 오른손 torso-local 위치는 이전 K1 참조와 거의 같았습니다. 이는 G1 원본과의 절대 자세 일치를 뜻하지 않습니다.

새 조준 모션은 QA 실패와 물리 0/3(약 1.56초 낙상)을 기록했습니다. 새 모션 생성·CSV 변환·QA·물리 평가·감사·영상 파이프라인은 있지만, UI Generate 버튼 자동 연결과 범용 모션 추종은 미완성입니다.

근거: [경례 개선](../workspaces/k1_kimodo_hx5/reports/salute_improvement.md), [조준 실패](../workspaces/k1_kimodo_hx5/reports/pistol_aim.md).
